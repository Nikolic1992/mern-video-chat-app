MERN Video Chat App 🎥💬
This is a full-stack video chat application built with the MERN stack (MongoDB, Express, React, Node.js) and WebRTC for real-time peer-to-peer communication. It allows two users to initiate a secure video call directly through the browser without the need for third-party services.

✨ Features
🔒 Secure peer-to-peer video calls (WebRTC)

🌐 Real-time signaling via Socket.io

👤 Unique user ID for call invitations

🔗 Simple UI to start or receive calls

🚀 Built with React (frontend), Node/Express (backend), and MongoDB (optional for scaling)

📦 Tech Stack
Frontend: React, Context API, WebRTC, Socket.io-client

Backend: Node.js, Express, Socket.io

Optional: MongoDB (future user data or session storage)

🛠️ Getting Started
Clone the repository
git clone https://github.com/Nikolic1992/mern-video-chat-app.git

Install server dependencies
cd server && npm install

Install client dependencies
cd ../client && npm install

Start the development servers

Run backend: npm run dev (from server folder)

Run frontend: npm start (from client folder)
